# calculator

Evaluate mathematical expressions and perform unit conversions.

## Capabilities
- Basic arithmetic (+, -, *, /, ^)
- Advanced functions (sqrt, sin, cos, log, etc.)
- Unit conversion (length, mass, temperature, currency)
- Supports variables and constants

## Usage
When invoked, this skill evaluates the given expression and returns the result.
