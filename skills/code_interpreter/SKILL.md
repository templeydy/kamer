# code_interpreter

Write and execute code snippets in a safe sandboxed environment.

## Capabilities
- Python code execution
- Data analysis with pandas, numpy
- Chart generation with matplotlib
- File I/O within sandbox

## Usage
When invoked, this skill executes the provided code and returns stdout/stderr output.
